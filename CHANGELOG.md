# История изменений

## 1.1.0
* Кардинальное уменьшение размера STEP: распознавание цилиндров, конусов, сфер, торов и аппроксимация
  криволинейных участков B-сплайнами (допуск 0,1 мм) вместо тысяч плоских фасет. Робот KUKA: 35,4 → 13,2 МБ.
* Сжатие STEP без потерь: удаление дублей точек и направлений, перенумерация сущностей.
* Новые параметры: `--no-fit`, `--fit-tol`; в окне — галочка «Распознавать поверхности» и допуск.

## 1.0.0
* Первая версия: конвертация .vcmx (layout и компоненты) в STEP AP214 со структурой сборок.
* Примитивы KUKA.Sim → аналитические тела; встроенные сетки 3DS → плоские грани B-rep, без треугольников.
* Предупреждение «В файле не хватает встроенных моделей», поиск компонентов по VCID в указанных папках.
* Окно (tkinter) и командная строка, установщик Inno Setup, автообновление из GitHub Releases.
